# Python / Pandas Data Preparation

This folder contains the Python scripts used for the initial
data inspection, profiling, contact-history generation, and
voter-data cleaning stages of the project.

## Workflow

1. `01_inspect_data.py` - Initial dataset inspection
2. `02_profile_data.py` - Data-quality profiling
3. `03_generate_contact_history.py` - Contact-history generation
4. `04_clean_voter_data.py` - Voter-data cleaning and preparation

The original ERICA-derived voter-level data is not included in
this public repository.
